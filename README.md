# Sagar Prajapati — Mobile portfolio

Recruiter-friendly site for an iOS / React Native developer. Live at
[https://sagarpra98.github.io/portfolio](https://sagarpra98.github.io/portfolio).

## Update your content

Edit **one file**: [`src/Data/profile.js`](src/Data/profile.js)

That’s where name, title, links, skills, apps, education, and contact details live. Screenshots stay in `src/Data/Portfolioimg/`. Resume stays in `src/assets/pdf/`.

## Local

```bash
npm start
```

Opens at `http://localhost:3000`. Check both desktop and a phone-width window.

## Deploy to GitHub Pages

```bash
npm run deploy
```

This builds the site and pushes the `gh-pages` branch. GitHub Pages should serve from that branch, with the site URL matching `homepage` in `package.json`.
